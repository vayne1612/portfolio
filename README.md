# Portfolio — Risal Darmala

Personal portfolio website. Static HTML/CSS/JS.

**Live**: https://risal-dev.web.id

## Stack

- HTML5, CSS3, JavaScript (vanilla + jQuery for legacy widgets)
- [AOS](https://michalsnik.github.io/aos/) — scroll animations
- [Typed.js](https://mattboldt.com/demos/typed-js/) — typing effect
- [Devicon](https://devicon.dev/) — tech stack icons
- [Font Awesome 6.5.1](https://fontawesome.com/) — UI icons
- [Web3Forms](https://web3forms.com/) — contact form (with hCaptcha)

## Local development

Pakai Laragon / XAMPP / live-server. Tidak ada build step.

```bash
# dengan npx live-server
npx live-server
```

## Deployment

Auto-deploy ke Vercel pada setiap push ke `main`.
